Timestamped JSON receipts хранятся в artifacts и обычно не входят в Git.
Их отсутствие в чистом clone означает отсутствие локального файла доказательства,
а не успешный или проваленный повторный прогон. Повторять указанную команду либо
получать исходный receipt; не восстанавливать результат по старому тексту.

Полный canonical receipt до выделения пакетов сохранён отдельно:
`artifacts/verification/canonical_before_modularization_20260910.json`.
Ссылка `canonical_latest.json` в исторических текстах была указателем на последний
прогон того момента; для прежних 2961 + 183 тестов использовать сохранённую копию.
