# GeminiVM: явные модели Flash и Pro — 21 сентября 2026

GeminiVM принимает `flash`, `pro` и совместимый alias `gemini-web` → `pro`.
В шлюзе5 доступны `geminivm/flash` и `geminivm/pro`; оба старых имени,
`gemini-web` и `geminivm/gemini-web`, направлены в Pro. Resilient-профиль также
начинает с Pro. Основная модель COS не изменена.

Выбор режима и весь запрос защищены существующей блокировкой рабочего стола.
Каждый запрос получает собственное представление конфигурации. После проверки
READY и URL распознаётся текущий селектор; при необходимости открывается меню,
проверяются шаблоны его пунктов и выбирается нужный режим. Видимая метка
проверяется после выбора и после ввода текста, до отправки. Нераспознанные состояния
останавливают запрос. Одновременное обращение к занятому браузеру получает busy.

HTTP-ответы и журнал GeminiVM сохраняют запрошенное имя, разрешённое имя и
распознанную метку браузера. Шлюз передаёт ограниченный набор diagnostics также
в успешных ответах; кеш для GeminiVM отключён. Cooldown учитывается по модели,
а ограничение одновременности остаётся общим для одного браузера.

Владение: GeminiVM `model_routes.py` разрешает имена, `browser_model.py` выбирает
и проверяет видимый режим, `config.py` валидирует маршруты и калибровку,
`core.py` владеет исполнением под lock. Шлюз владеет маршрутизацией и fallback.
В COS не добавлено специальных веток для моделей. Документация обоих внешних
проектов обновлена. DOM/OCR/CDP/скрытые API не используются.
