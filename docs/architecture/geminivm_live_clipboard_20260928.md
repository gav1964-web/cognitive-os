## Результат работы COS

Analyzer изучила захват; Architect предложила отдельный ограниченный проектор
в `geminivm/response_projection.py`, подключённый из `same_chat_followup.py`,
с точным сравнением, сохранением исходных байтов, отказом при неизвестной
структуре и сохранением проверок URL/генерации/попыток. Web-source extraction
должен остаться прежним. Проектирование принято, реализации ещё нет.

SpecWriter и аудитор последовательно обнаруживали пропущенные различающие
проверки: порядок списков, границы изображения, неизвестные структуры,
отсутствующая/неоднозначная принадлежность Markdown-panel. Последнее замечание:
дубликаты должны находиться внутри корректной цепочки владельцев, иначе тест
проходит из-за отсутствующего контейнера и не проверяет неоднозначность.
Полная спецификация не допущена; Programmer/Reviewer на этом расширении
не запускались. Общие баллы ролей не повышаются.

`format-source`, цель `goal-observed-format.txt`. Полный двухфайловый черновик:

независимые тесты, затем реальное восстановление. Изменения должны оставаться
применимыми к другим проектам. Увеличение общего предела — только явно владельцем.
