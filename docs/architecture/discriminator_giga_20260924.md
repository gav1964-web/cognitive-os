# GigaChat на том же запросе и аудит шлюза: 24 сентября 2026

GigaChat Pro получила точные сообщения предыдущей проверки DeepSeek и тот же
rubric. Дизайн также отклонён: модель перепутала лишнюю вставленную запятую
с недостающей и предложила неправильное действие для A. Патч не запрашивался.
При разборе обнаружен отдельный дефект адаптера GigaChat в шлюзе 5: параметры
генерации не передаются, usage теряется. Следующая работа — контракт адаптера,
а не новые подсказки или перестройка ролевой архитектуры COS.

GigaChat утверждает, что A не хватает запятой, хотя требуется убрать лишнюю
вставку форматтера. Для B пишет «запятая уже была», хотя её добавление —
ожидаемый эффект. Для C отрицает применение callback вопреки наблюдениям.
Предикат требует окончания элемента AST, но ответ утверждает, что `_fix_literal`
уже получает все данные; фактически аргументы — индекс, токены и boolean.
Источник недостающих данных не описан. Смысловая проверка выполнена ассистентом.

При непустом ответе COS получила нулевой usage и правильно сохранила расход
как неизвестный. Один HTTP из COS; число внутренних обращений к API не измерено.
Следующих LLM-вызовов не было. Исходный корпус, COS runtime и профили не изменены.

## Что найдено в текущем коде шлюза 5

Read-only аудит и офлайн-вызов точных методов с фиктивными клиентами подтвердили:

- `GigaChatAdapter.generate_result` принимает `max_tokens`, `temperature`,
  `top_p`, `response_format`, но не передаёт их в `GigaClient.get_answer`.
- Без `model_params` оркестратор использует temperature=0.8; OpenAI-обработчик
  задаёт 0.2, которое этот адаптер игнорирует. Равенство настроек не обеспечено.
- Giga transport возвращает только текст ответа, отбрасывая API usage;
  адаптер возвращает `usage=None`, а OpenAI-совместимый выход превращает его
  в нули. Нулевую стоимость из этого выводить нельзя.
- Внутренний retry policy допускает три попытки. Один вызов из COS не доказывает
  единственный вызов внешнего API; фактическое число здесь неизвестно.
- Контекст данного запроса не обрезается текущим `ContextManager`: 21791 символ
  меньше порога 32000. Офлайн проверено сохранение всех сообщений.
- OpenAIAdapter в аналогичной офлайн-проверке передаёт параметры и сохраняет
  фиктивный usage. Это проверка текущего кода, не перехват живого трафика.

Хеши всех исследованных файлов и точный scope сохранены в `transport-audit.json`.
Сам шлюз не изменялся. Причинная связь этих дефектов со смысловой ошибкой
ответа **не доказана**; сравнение нельзя считать контролируемым рейтингом моделей.

## Ошибка предварительной проверки ассистента

До вызова был сохранён резерв 248304 токена на дизайн и условный патч с выходом
до 32768. Проверялись ограничения на входе COS, но не их прохождение через
конкретный адаптер и его внутренние повторы. Найденный код не обеспечивает
заявленный предел на стороне провайдера. Исходный протокол сохранён; его резерв
нельзя выдавать за подтверждённую верхнюю границу расхода этого маршрута.
После неизвестного usage дальнейшие вызовы остановлены. Фактический расход
остаётся неизвестным, превышение или соблюдение резерва не утверждается.
