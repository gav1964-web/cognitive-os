# Служба COS: шлюз 8200 и завершённый ролевой прогон

29 сентября 2026. По указанию пользователя COS переведена с 8000 на 8200.
Изменены профили, bootstrap-команда, CLI/default endpoints и адрес в новых
шаблонах web research. Старые измерения и распознавание legacy-адресов сохранены.
Bootstrap запустил шлюз 5 скрытым процессом; health200 подтверждён. Старый
слушатель 8000 остановлен после проверки его точной команды и готовности 8200.
Переустановка службы и изменение firewall/VPN не выполнялись.

Первый короткий запрос из ролевого Python истёк по таймауту. Последующие проверки
всех трёх Python под `NT SERVICE\CognitiveOSWorker` получили HTTP200; повторная
проверка ролевой среды завершилась за 0,641 с. Это подтверждает доступность,
но не устанавливает причину прежней блокировки или первого таймаута.

## Ошибка переноса истории учёта

Первый Programmer получил кэшированный ответ с нулевым usage. Адаптер перенёс
ledger, но не доказательства предыдущих оплаченных запросов. COS сохранила
198903 токена резерва и остановилась; бездоказательного освобождения не было.
Сверка сохранённой истории установила точное совпадение request digest, модели,
лимита ответа, response format и самого ответа с уже учтённым вызовом.
`reconcile_feature_usage` создала отдельный ledger, сохранив все 11 записей.

`remote_role_job.v1` теперь допускает опциональное `known_calls` — отображение
абсолютных путей файлов истории в их хеши. Старые задания без поля работают.
Worker проверяет хеши и целостность запросов перед использованием и передаёт
историю в `FeatureChat` только как доказательство учёта. Она не воспроизводится
как принятое ролевое решение. Неподтверждённый кэш, другая модель/задача/ответ
или отсутствующий оплаченный slot сохраняют неизвестный расход и остановку.

Ассистент исправил адаптер COS и подготовил новый выпуск. Этот этап не является
новым испытанием установки подписанного self-patch. Первоначальное обращение и
состояние контроллера оставлены историческими; продолжение явно использует
сверенный ledger, который заменяет прежнюю оценку неизвестного резерва.

## Результат

Служба повторно проверила принятую спецификацию и продолжила с Programmer и
Reviewer через `dslab-gpt6-luna`. Первые три ролевых артефакта, frozen tests и
исходный семифайловый снимок шлюза сохранены побайтно. Кандидат сформирован COS.

- 23/23 native-теста при сборке кандидата.
- 36/36 отдельно зафиксированных внешних случаев.
- Успешное служебное продолжение: 29,422 с, два обращения, одно из кэша.
- Всего на этом этапе три обращения: два cache hit и одно с новым usage.
- Новый учтённый расход 4636; вся серия 57861, неизвестный расход 0,
  общий предел 450000. Исторические 53225 не сбрасывались.

Это проверка конкретного continuation/deployment, а не новые общие баллы ролей.
Кандидат остаётся отдельным снимком, исходники production-шлюза не установлены.
Учёт не является счётом провайдера и не включает текущую сессию Codex.
SCM stop/restart во время активной работы остаётся отдельной проверкой с правами
администратора; текущий Alex token таких прав не имеет. Изоляция всего хоста
не заявляется.

Регрессии: 72 проверки адресов/шаблонов; 37 проверок continuation/inference/cache.
