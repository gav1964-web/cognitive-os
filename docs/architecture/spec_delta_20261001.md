# Точечные исправления спецификаций и восстановление DNS — 01.10.2026

Этап исправляет два общих механизма COS. Изменений исходных map/5 нет;
все целевые предложения и тесты по-прежнему написаны ролями COS.

## Реализовано

- `unaccepted_spec_delta.v1`: явные добавления тестов и замены уникального текста
  в непринятом черновике. Хеши связывают базу с целью, дизайном и исходниками.
  Неупомянутые тесты/поля сохраняются точно; удаления и изменения frozen-тестов
  запрещены. COS может обновлять метаданные явно. Развёрнутый результат снова
  проходит контракт, аудит и native qualification. Resume проверяет исходный
  запрос, развёрнутую спецификацию и соответствующий аудиторский receipt.
- Синтаксический отказ production proposal возвращается Programmer с его
  предложением и диагностикой. Разрешена одна коррекция на попытку, затем
  сохраняется отказ. Старый checkpoint можно возобновить только после проверки
  goal/source/design, квалификации тестов и воспроизведения SyntaxError.

Это транспорт правок, а не предметная KB. Runtime не пишет проверки и не
исправляет семантику вместо модели. Новые механизмы применимы к другим проектам.
