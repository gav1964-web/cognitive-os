# Проверка эффекта переданного контекста — 18 сентября 2026

Пакет проверяет ранее исправленную передачу контекста и объяснение предусловий.
Новых изменений production runtime и переключения defaults в этом этапе нет.
Измерения уточнили следующий план; принятого ремонта и основания повысить баллы нет.

## 1. Контрольное сравнение ремонта

Вход гипотезы побайтно совпал с предыдущим сохранённым запросом. Её настоящий
ответ использован повторно без нового inference; это явно отражено отдельно от
logical_model_calls в receipt COS. Генератор кандидата получил новый контекст
вызовов, включая `List[Tuple[Optional[Key], Item]]`. Один запрос: 9 120 токенов.

Кандидат повторил прежнюю неработающую проверку одного Comment. После отказа
выполнен один заранее предусмотренный прямой маршрут без модельной гипотезы:
7 094 токена. Он тоже получил интерфейсы и историю контрпримеров, но вернул
побайтно тот же код. Оба ответа пришли без gateway cache hit.

Полные native-прогоны обоих кандидатов: **33 passed, 1 failed, 2 xfailed**,
новых регрессий нет. Исходный корпус не изменён. Reviewer не достигнут.
Передача контекста теперь подтверждена запросами, но улучшения ремонта нет.
Один потреблённый случай не доказывает предел способности модели; прямой маршрут
меняет также построение запроса, поэтому это не изоляция единственного фактора.

## 2. Проверка запрошенных моделей

Repair L4.5 запрашивает `deepseek/deepseek-chat`; описание —
`deepseek/deepseek-v3.2`. Конфигурация шлюза допускает оба идентификатора, а его
OpenAI adapter возвращает выбранное имя вместо независимого `response.model`
провайдера. Это разные запрошенные маршруты, не доказательство того, какие именно
модели обслужил внешний провайдер. Нельзя приписывать результаты ремонта v3.2.
Конфигурация и исходники внешнего шлюза прочитаны без изменений.

## 3. Адресный вопрос о предусловиях

Те же полные исходники Replay поданы модели с общим вопросом: проследить значения
по умолчанию, проверки и обработку исключений до указанного успешного статуса.
Вопрос не содержит ответа о конкретном параметре. Получено 8 183 reported tokens.

Ответ противоречив: для environment_profile указано `success_when_omitted=yes`,
но объяснение правильно заканчивается выводом, что пустой профиль не пройдёт
валидацию и успех недостижим. Валидная JSON-схема и ссылки на исходники не делают
такой вывод достоверным. Этот результат нельзя использовать как готовый факт.

## 4. Полное описание и тайм-аут

Writer получил исходники и эти предварительные заметки с требованием проверять
их по коду. Клиент остановился через 240 секунд, серия закрыта без повторов.
Шлюз завершил запрос через 263,657 секунды. Текст восстановлен из кеша по точному
хешу provider/model/messages/options, без нового обращения к модели.

Частичное улучшение: в unknowns появилось указание, что успех зависит от валидного
профиля. Однако список входов по-прежнему без пояснения называет его опциональным;
необходимость передачи профиля для успеха не объяснена согласованно. Флаги
неизменности снова описаны как подтверждение сохранности, хотя они диагностические.
Повтор baseline, SHA-256 и wheels сохранены. Основной критерий и лимит времени
не выполнены; преимущества, достаточного для включения режима, не установлено.

Заранее подготовлен свежий авторский контрпример с рабочим profile по умолчанию.
Его поведение проверено локально, но модельный контроль не запускался после
неизвестного расхода writer. Это не завершённая оценка переноса на другие проекты.
