# Пользовательская задача DWG через COS — 25 сентября 2026

**Задача продукта не завершена. Исходники VR не изменены.**
Пользователь задал улучшение преобразования DWG для отображения стрелок,
размеров и подобных элементов. Ассистенту разрешено менять только COS;
предметные тесты, код и применение должен выполнять сам COS, без специальных
веток VR в его общем коде. Эта граница соблюдена.

## Что сделано в COS

Создан [общий экспериментальный маршрут](feature_development.md)
`tools/develop_feature.py`: модель сама выбирает исходники, Analyzer передаёт
анализ Architect, SpecWriter создаёт новые тесты до production-кода, Programmer
готовит точные замены. Затем COS сравнивает версии, получает review и может
применить проверенные байты своей транзакцией с backup и откатом. Прежний
programmer MVP сохраняет запрет source apply; его authority не расширялась.

Общие исправления, проверенные в процессе: ограниченный отбор исходников без
архивов и runtime outputs, чтение частями, объединение перекрывающихся строк,
сохранение контекста между продолжениями с повторной проверкой хешей, ограниченная
обратная связь на неполный ответ, контекст каждой роли, отделение упомянутых
старых тестов от прав на запись, проверка бюджета перед следующим запросом.
Ни один предметный алгоритм DWG не добавлен в runtime или prompts COS.

**44 focused tests passed**, включая 24 проверки нового механизма и 20 прежней
цепочки regression feedback. Navigation и структурная canonical-проверка
пройдены, нарушений400-line gate нет. Полный общий тестовый набор не запускался.
Основное свидетельство: `artifacts/feature_goal_20260925/stage-finish-final.json`.

Функцию, алгоритм и предметные проверки ассистент модели не задавал. Данные
задачи содержат пути VR и знания о DWG; общий исполняемый код COS их не содержит.

они сохранены как read-only context с явной отметкой в эффективном контракте.

Общие числовые оценки ролей не повышаются. Сейчас подтверждён самостоятельный
переход от пользовательской цели к содержательному анализу и дизайну; завершённая
доставка и правильность улучшения на реальном DWG не подтверждены.
