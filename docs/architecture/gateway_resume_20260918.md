# Восстановление запуска шлюза и продолжение — 18 сентября 2026

Пользователь указал на ошибку ассистента: штатный запуск локального шлюза был
заранее согласован. Отсутствие listener ошибочно объявили внешним блокером,
не вызвав уже существующий bootstrap. Эта запись корректирует причину остановки;
старые receipts не удаляются и их расход не переписывается как нулевой.

## Исправление процесса

`ensure_llm_gateway` запустил настроенный сервис `F:/ubuntu/test/5`, health прошёл.
Первая попытка в sandbox не смогла записать рабочие логи шлюза; разрешённый запуск
с необходимым доступом завершился успешно. Исходники, настройки и credentials
самого шлюза не изменялись. Процесс работает без окна.

`BudgetedChat` теперь вызывает `ensure_llm_gateway_for_url` перед `start_call`
для штатного транспорта. Результат готовности сохраняется в записи запроса;
ошибка bootstrap не занимает слот inference и не создаёт неизвестный usage.
Внедрённый транспорт отвечает за собственную готовность. Правило добавлено в
AGENTS.md и development_workflow.md, чтобы экспериментальные запуски тоже его
соблюдали.

При полном описании выявлена вторая ошибка ассистента: max_output_tokens4500
превышал максимальные4096, объявленные текущим gateway OpenAPI/Pydantic-контрактом.
Получен HTTP422 без telemetry. Настроенный предел4096 теперь проверяется до
inference. Пара описаний продолжена с этим пределом; исходный422 сохранён.
Это явная коррекция запроса после диагностики, не скрытый автоматический retry.

## Проверки описаний

Шесть подготовленных авторских примеров получили ожидаемые модельные verdict:
refuted/supported/supported/refuted/uncertain/supported. Эффективные verdict
совпали с сырыми; на этой серии guard не менял ответы. Это положительный результат
на новых авторских контролях, но не независимый holdout и не измерение9.7+.

Пара полного описания использует одинаковые полные исходники Replay; различается
только общая инструкция о предусловиях API. Точные тексты, отдельная смысловая
оценка, usage и итог сохраняются в `artifacts/gateway_resume_20260918/`.

Оба полных текста получены. Baseline:8797 токенов/45,690с; expanded:8957/45,884с
по модельной телеметрии. Расширенный вариант вновь называет profile опциональным
без условия успешной квалификации; теряет явные два baseline-прогона и описание
возвращаемых флагов неизменности. Также приписывает исходному тесту ожидаемую
ошибку, хотя код сверяет повторные baseline-прогоны друг с другом. Baseline
сохраняет больше деталей, но тоже не объясняет последствия environment_profile=None
явно. По заранее заданным критериям расширение инструкции не принято; default
сохранён. Это одна пара ответов на одном проекте, не обобщённая оценка качества.

transport-сбоя. После HTTP422 отдельная поправка протокола переносит известный

наличие запаса не означает provider-attested billing ceiling. См.
`protocol.json`, `protocol_amendment.json`, оба budget JSON и raw attempts.

без telemetry. Предыдущий отказ соединения учитывается отдельно полным резервом.
Это не счета провайдеров; startup и инженерное время не входят в модельную latency.
