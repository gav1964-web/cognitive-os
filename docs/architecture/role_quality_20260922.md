# Первый пакет качества первых трёх ролей на Pro

22 сентября 2026. Ограниченный ремонт Python, не сертификация9.7+.
Все источники проектов неизменны; модельные кандидаты не исправлялись ассистентом.
Пакет ограничен восемью HTTP-обращениями с сохранением отказов; usage GeminiVM
неизвестен, токеновый резерв не является подтверждённым расходом.

## Что изменено

1. План актуализирован: native feedback уже реализован, транспортные проверки
   не повышают оценки ролей. Приоритет — причинный диагноз, выполнимый дизайн,
   достаточная спецификация и поведенческий результат.
2. На известной tuple-задаче Pro предложила сравнение AST с возвратом исходного
   файла. Первый кандидат содержал синтаксическую ошибку и был отклонён.
3. Исправлена потеря текста на передаче между ролями: принятый диагноз/дизайн
   больше не обрезается после1200 символов, preservation после800. Объявлены
   пределы4000/2400 и отказ при превышении; строки проходят без изменений.
   Существующий opt-in форматный повтор теперь передаёт фактические ошибки
   Python-парсера модели. По умолчанию повтор по-прежнему выключен.
4. Один новый запрос исправил синтаксис. Native regression приняла патч, но
   поведенческая проверка выявила потерю форматирования соседнего списка.
   Этот успех **аннулирован**; исходный положительный receipt сохранён.
   Плагин `python_transform_contracts`0.2.0 теперь владеет явно выбранным
   контрактом независимых фрагментов: исходный no-op, положительный пример и
   обе комбинации. Примеры связаны с native source; положительный результат
   должен дважды подтверждаться на baseline. Тот же неверный патч получает
  132 passed /2 failed на расширенном наборе. Identity-only тоже отклоняется.
5. Подготовлена и предъявлена модели новая задача humanize metric:
   пять целевых ошибок,837 исходных проверок проходят. Это новая задача известного
   репозитория, не независимый holdout. Upstream production fix не читался.
   Pro дала конкретный диагноз округления внутри SI-диапазона. Получение патча
   прервалось из-за провайдера. [Исправлены уведомление и ожидание на пустой
   странице](geminivm_notice_20260922.md), но повтор также потерял контекст
   ответа. Причина возврата интерфейса на главную остаётся открытой.

Гипотеза и дизайн в этом контуре объединены в одном модельном запросе; SpecWriter
связывает требования с проверками. Не выдавать это за три независимых вызова Pro.
Старые уровни9,2/7,0/6,5 остаются исторической калибровкой; новых общих баллов нет.
У tuple-примера диагноз правдоподобен, дизайн недостаточен, прежний acceptance
пропустил дефект. Новая проверка закрывает этот конкретный класс ложного успеха.
