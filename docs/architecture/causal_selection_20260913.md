# Проверка причинных предложений до выбора ремонта

Дата: 13 сентября 2026. Область — существующие учебные правила и доверенный
проект в отдельных subprocess-копиях. Независимых оценок 9.7+ этот этап не даёт.

## Что изменилось

Прежний `infer_causal_hypothesis` выбирает первое совпадение с учебной базой.
Новый режим перечисляет все совпадения (не более четырёх), строит предложения
существующими операторами и проверяет каждое на неизменённых native-тестах.
Новых правил ремонта или диагностических тестов EnvForge на этом этапе нет.

| Роль | Новый результат |
|---|---|
| Analyzer | Исходные предложения, два повторения сбоя и результат вмешательства; совпадение с KB отделено от наблюдаемого эффекта |
| Architect | Единственное поддержанное предложение, исходная предпосылка, механизм изменения и обязанность полной регрессии |
| SpecWriter | Выбранный operator, evidence packet и сравнительный эксперимент внутри ImplementationDelta |
| Reviewer | Целостность выбора и точное совпадение inventory итогового patch с предварительно испытанным |

Два разных patch, проходящих те же тесты, дают `ambiguous`, а не выбор по порядку.
Сбой окружения, неполные данные, неподдержанный кандидат, дубликат или отсутствие
изменения не дают однозначного выбора. Если сравнение не удалось, прежняя учебная
authority удаляется; обратная связь возвращается Analyzer. Автоматических повторов
пока нет. После предварительной проверки нужны полная регрессия и финальный Reviewer.

## Сквозной прогон

На уже потреблённом EnvForge новый режим автоматически проверил существующее
учебное предложение до передачи дизайна. Источник, fixture и KB сохраняют прежнее
авторство ассистента; новая независимая причинная гипотеза не получена.

- `artifacts/verification/causal_selection_linux_20260913.json`: предварительное
  вмешательство поддержано, полная native suite прошла, финальный Reviewer
  отклонил несовпадение байтов patch. Упаковщик нормализовал CRLF в LF.
- Упаковщик учебного ремонта теперь читает/пишет байты UTF-8 без преобразования
  переводов строк. Добавлены проверки LF и CRLF; gate точного совпадения сохранён.
- `artifacts/verification/causal_selection_linux_v2_20260913.json`: повтор завершён
  `experiment_validated`; **85 native tests passed**, финальный Reviewer `approve`.
  Исходный проект, рабочий COS и замороженная копия COS не изменились.
- Первая техническая попытка до этих receipts остановилась на `FileExistsError`
  при подготовке временной копии; роли в ней не запускались.

Вызовов LLM — 0. Новых ручных диагноза/patch для прогона нет, но существующие
оператор и fixture написаны ассистентом раньше. Это проверка интеграции и эффекта
вмешательства на известном случае, не самостоятельное решение нового дефекта.
Поддержаны один failure issue, один production-файл и до восьми подписанных
failing nodeid. В EnvForge реально сравнивался один кандидат с исходным поведением;
несколько альтернатив проверены отдельными регрессиями, не независимыми случаями.
Полнота поиска причин и caller analysis не доказаны.

## Использование

`run_project_development(..., authorize_training_replay=True,
validate_causal_proposals=True, run_sandbox_experiment=True)` включает новый режим.
CLI: `tools/project_development.py --authorize-training-replay
--validate-causal-proposals --run-sandbox-experiment` с обычными параметрами проекта
и chain-report. Одновременный LLM advisory отклоняется: сравниваются существующие
учебные правила. Без флага прежние маршруты сохраняются. Структурированный
`task_contract` прошлого этапа остаётся planning-only; общий переход к исполнению
ещё не реализован.

Основные файлы: `runtime/upstream_causal_selection.py`,
`runtime/upstream_causal_trials.py`, `runtime/upstream_causal_review.py`.
Пробы исполняет существующий `native_failure_acceptance` через Replay.

Регрессии проверяют неверный ремонт с перепривязкой списка, два проходящих
решения, устаревший packet, отсутствие authority, подмену выбранного patch и LF/CRLF.
Receipts: `artifacts/verification/causal_binding_20260913.xml`,
`artifacts/verification/causal_newlines_20260913.xml`,
`artifacts/verification/development_stage_causal_20260913.json` (финальный снимок,
регрессии, предел 400 строк), `artifacts/verification/canonical_causal_20260913.json`.
Отдельная установка пакетов: `artifacts/verification/subprojects/6a0ec9a7/report.json`,
по 27 успешных тестов Inspect и Replay.
