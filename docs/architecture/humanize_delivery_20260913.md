## Что изменилось

- Источник теста включает decorators с параметрами; одинаковый текст группируется
  с сохранением всех nodeids. Ранее тело повторялось, список параметров отсутствовал,
  а hypothesis envelope включал лишь первые четыре test-source записи.
  Превышение длины excerpt явно помечается; общий лимит prompt не снят.
- Ответы гипотезы и кандидата описаны JSON Schema. У `confidence` больше нет
  образца ответа `0.0`; порог допуска 0,6 сохранён. Отклонённая гипотеза оставляет
  ограниченную диагностику с отдельной неисполняемой областью применения.
- Кандидат запрашивается как одна функция с локальными imports. Предпочтителен
  один дизайн; несколько нужны для разных причинных механизмов, а не вариантов
  записи одного решения. Validator продолжает отклонять лишние поля и код вне функции.
- `model_candidate_format_retries` в policy: по умолчанию **0**, допустимо **1**.
  Модель получает конкретную ошибку формата и сама возвращает новый полный ответ.
  Исходный ответ не редактируется и сохраняется. Повтор не применяется к отказу
  по confidence, изменению интерфейса, provenance или провалу native-тестов.
  При включении — максимум три логических вызова вместо двух; native gates прежние.

## Попытки и вмешательства

Каждая попытка сохранила declaration, inventory COS, новый native intake, transcript,
telemetry и result. Контрольный вход — прежняя неизменённая копия baseline с пятью
падениями. Ассистент менял COS и формулировки протокола между попытками; код ремонта
за модель не писал и её ответы не исправлял. Первые неудачи не переоценены как успех.

| Попытка | Логических вызовов | Результат | Reported tokens |
|---|---:|---|---:|
| `attempt_01` | 2 | Гипотеза DeepSeek принята; таймаут запроса кандидата → GigaChat-Pro; его imports вне функции отклонены | 3635 |
| `attempt_02` | 2 | Кандидат DeepSeek содержит лишний schema_version, controlled stop | 4250 |
| `attempt_03` | 3 | Один включённый повтор вернул тот же некорректный ответ; controlled stop | 4911 |
| `attempt_04` | 2 | После формальной JSON Schema: один корректный кандидат, native regression и финальный approve | 4400 |

Итого: **9 логических вызовов, 10 transport events, 17196 сообщённых токенов**.
Пять успешных ответов сообщили нулевое usage; ещё один transport event — таймаут
без usage. Это не подтверждённый биллинг и не полная оценка затрат, включая работу
ассистента. В успешной попытке дополнительный форматный повтор не понадобился.
Изменения входа, schema и модели не составляли независимый факторный эксперимент:
нельзя приписать весь эффект одному изменению или одному значению confidence.

## Шлюз и стоимость

Read-only исследование обнаружило исходники процесса шлюза в `F:/ubuntu/test/5`.
В просмотренном OpenAI-пути текст ответа передаётся без добавления schema_version.
Кеш учитывает сообщения и параметры запроса. При cache hit он возвращает usage=None,
а OpenAI-совместимый ответ заменяет отсутствующие счётчики нулями. Заголовок
`X-Cache-Hit` существует, но текущая telemetry COS его не сохраняет.
Свидетельство: `gateway_source_inspection.json`; credentials и кеш чужих запросов
не читались, исходники шлюза не менялись. Это не аттестация каждой строки кода
работающего процесса и не доказательство происхождения каждого старого ответа.
Failover реально наблюдался по таймауту; исчерпание квоты этим не проверено.
