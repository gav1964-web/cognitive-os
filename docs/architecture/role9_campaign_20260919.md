  Pytest selection-output bookkeeping survives upstream tests mutating sys.argv.

  preflight, trials and requested acceptance. Missing plugins previously produced
  false infrastructure failures in pydash; they were not model-quality failures.
- Project-map plugin owns bounded test-data syntax interpretation. Intentionally
  invalid fixture files remain visible as noise instead of routing all work to
  damaged-source recovery. Production syntax errors remain blocking evidence.
- Existing executable doctests must survive candidate replacement. Full native
  verification now compares original and candidate test selections, skips,
  completion and source invariants in separate copies. The v3 role evaluator
  requires a valid regression-scope receipt before granting validated-change
  credit. Thresholds and training caps were not relaxed.
