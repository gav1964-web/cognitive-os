# GeminiVM: сокращение SSH-вызовов при проверке фокуса

23 сентября 2026. Изменение установлено; перезапущен только HTTP-сервис8002
при свободном desktop и отсутствии HTTP-запросов. Firefox и VM не перезапускались.

## Изменение

Прежде каждый key/click/park отправлял отдельный SSH-запрос проверки активного
окна, а затем второй запрос действия. Теперь focused_action выполняет свежую
проверку и одно действие одной удалённой shell-командой. Ошибка чтения фокуса,
пустой, неоднозначный или чужой ID останавливают команду до действия.
Сбой самого действия сохраняется как ошибка SSH, без повторной отправки.

Проверка не кэшируется: следующее действие снова проверяет окно. Заданные
задержки, clipboard readback, проверка принадлежности ответа и общий deadline
сохранены. Отдельные проверки фокуса при наблюдении экрана остаются.
Команда содержит только внутренние действия и проверенный числовой ID окна;
пользовательский prompt в shell не интерполируется.

Один SSH-вызов устраняет сетевой промежуток между проверкой и действием,
но не делает ввод атомарным относительно оконного менеджера: внешний перевод
фокуса после проверки всё ещё возможен.

## Проверки и измерения

474 теста GeminiVM прошли, включая19 новых. Негативные проверки выполняют
настоящий POSIX-guard с подставным xdotool: чужой/пустой фокус, ошибка запроса
даже с подходящим stdout, смена фокуса между действиями, ошибки действия,
недопустимый ID окна. Сохранены прежние тесты восстановления, JSON-контракта,
deadline, очистки истории и защиты15 старых диалогов.

| Проверка | До | После |
|---|---:|---:|
| SSH-вызовы в одинаковом тестовом цикле | 77 | 60 |
| Отдельные проверки фокуса в этом цикле | 26 | 9 |
| Медиана реальной SSH-проверки с пустой операцией | 1,829с | 0,921с |

В тестовом цикле одинаковы отправленный prompt, ответ, одна отправка, отсутствие
повторов и3с времени управляемых часов. Это проверка сохранения поведения,
не живой запрос к модели.17 объединённых действий убрали17 SSH-вызовов.

Реальный SSH-замер использовал3 чередующиеся пары старого и нового вариантов
под общей блокировкой: только чтение активного окна и пустая операция.
Отдельный контроль чужого ID на реальной оболочке остановился до действия.
Всего11 SSH-вызовов; клавиш, кликов, clipboard-операций и LLM-вызовов —0.
Медиана этой операции уменьшилась на49,6%. Полная задача с генерацией не
измерялась заново; прежние82с подготовки и291с полного цикла не пересчитаны.

Установка проверила исходные/новые SHA256 и лимит400 строк, сохранила резервные
копии. Публичные контракты GeminiVM, шлюза и COS не менялись.

## Дальше

На следующей полезной авторизованной задаче измерить подготовку, генерацию
и чтение результата отдельно. Не запускать повтор форматтера только ради
тайминга. Оставшиеся SSH-вызовы оптимизировать по фактическому профилю, сохраняя
проверки. Работа над source-bound выбором места ремонта остаётся продуктовым
приоритетом; этот этап не дал нового ремонта или повышения оценок ролей.
