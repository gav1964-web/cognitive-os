Предыдущий бюджет из шести обращений закрыт. Новый бюджет из пяти запросов

## Четыре инженерных шага

1. Отдельный контракт review одного утверждения: supported/refuted/uncertain,
   объяснение, точные цитаты и необязательный исправленный текст. Инструкция
   принадлежит плагину project_description0.4.0 и не содержит предметных подсказок.
2. Подготовка ограниченного запроса: исходный отчёт и утверждение связаны digest,
   источники — SHA256. Можно явно дочитать до трёх функций или диапазонов из
   исходного каталога. Контекст доказательств ограничен12тыс. символов; инструкция
   и текст утверждения добавляют небольшой объём сверх него.
3. Проверка ответа: существующие ID и дословные цитаты обязательны для supported
   и refuted. Вымышленная цитата, устаревший файл, timeout или невалидный ответ
   оставляют failed receipt. Запуск делает один запрос без retry/fallback.
4. Предложения сохраняются отдельно от фактов, привязаны к исходному отчёту и
   задачам review. Задачи не закрываются автоматически. Предложения могут дойти
   через product_context до Analyzer → Architect → SpecWriter с повторной проверкой
   источников и цитат; права на исполнение не появляются.

CLI: `tools/review_description_claim.py prepare|run|attach`.
Проверенная цитата подтверждает только наличие текста; смысл вывода не становится
независимо сертифицированным. Runtime не переписывает принятое описание.

## Пятый шаг: выполненное измерение

Фиксированы пять отдельных запросов: выбор модели по сложности, смысл `/health`,
область глобального обработчика ошибок в проекте5, отрицательный контроль
«наличие литерала не равно реализации» и положительный контроль локального fallback.
Первые три — известные ошибки, два последних — синтетические примеры; это не blind holdout.
Ожидания лежат вне запросов и не отправляются модели.

Согласованный бюджет: максимум5 запросов DeepSeek v3.2, по одному на случай,
без повторов и fallback, timeout240с; максимум1600 выходных токенов на запрос.
Все пять подготовленных входов вместе:20891 символ. Это не точный прогноз токенов
или стоимости. При транспортном сбое серия прекращается без повторной попытки.

Материалы: `artifacts/description_resolution_batch_20260917/protocol.json`,
пять `*_job.json`, `prepare_suite.py`, `run_suite.py` в той же папке.
Тесты, навигация, пакеты и размерный gate относятся ко всему инженерному пакету;
они не считаются отдельными шагами. Receipt: `finish.json`.

### Результат живой серии

Все пять ответов получены без повторов, fallback и транспортных ошибок.
Проверка формата и дословных цитат прошла 5/5. По телеметрии шлюза:
8310 токенов (5855 входных и 2455 выходных), суммарная задержка запросов
87,182 секунды; все пять ответов помечены cache_hit=false. Это показания шлюза,
не платёжные документы. Сравнивать эту сумму со стоимостью полного описания
проекта некорректно: здесь проверялись пять заранее выбранных утверждений.

| Случай | Ответ COS | Сверка ассистентом по исходникам |
| --- | --- | --- |
| Выбор модели по сложности | supported | Условный выбор и имена fast/qwen распознаны верно; прежнее отрицание наличия этих имён не повторилось. Фактическое исполнение алиасов локально/в облаке выбранными фрагментами полностью не доказано. |
| `/health` | uncertain | Верно замечено отсутствие индивидуальных статусов; предложено полезное уточнение. Ожидался refuted, однако в подготовленном контексте отсутствовала привязка функции к маршруту. Это ограничение подготовки эксперимента. |
| Область обработки ProviderError | supported | Ошибка: локальный перехват прямо виден и процитирован, но сохранено «в любом обработчике — глобальным». COS также признала неточность HTTPException, однако подтвердила исходное составное утверждение. Предложенное исправление всё ещё неверно. |
| Литерал CSV при реализации JSON | refuted | Верно: наличие константы не доказывает формат результата. |
| Локальная обработка без внешнего обработчика | supported | Верно для показанной ветки remote is None. |

Не сводим результаты к общей оценке роли: два синтетических контроля пройдены,
одна известная ошибка о наличии имён устранена в этой попытке, `/health` частично
уточнён, одна явно ложная генерализация подтверждена вопреки цитируемому коду.
Цитаты проверяют наличие текста, но не логическое следование вывода.

Ассистент вручную выбрал утверждения и функции. Это проверка reviewer на
подготовленном контексте, не доказательство автономного поиска свидетельств COS.
Протокол и ответы не менялись по ходу серии. Ошибочный ответ сохранён целиком;
он не принят как факт и не передан ролям как исправленное описание.
Никакие новые предложения этой серии не переписывали прежний отчёт или задачи.
