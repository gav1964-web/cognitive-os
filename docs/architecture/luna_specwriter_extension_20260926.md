## Полученный результат

Статус **spec_qualified** теперь охватывает путь
`BlockResolver → normalize_entity → normalized_to_geojson` на синтетическом
объектном входе, а также прежние контракты экспорта, границ и преобразования
координат. Luna создала один дополнительный файл114 строк с двумя тестами:

- DIMENSION с принадлежащим ему LINE в анонимном блоке должен отдавать дочернюю
  линию в GeoJSON с правильными координатами и `dimension_handle`;
- DIMENSION без резолвера должен сохранить прежний единственный GeoJSON feature.

Фикстуры реализуют только входной интерфейс документа и сущностей. Настоящие
production-классы и функции исполняются, их результаты не подменяются. Первый
тест падает на отсутствии дочерней графики, второй проходит. Предметный тест
ассистент не правил. Родительские пять случаев сохранены байт-в-байт.

Итого исходная версия: **4 ожидаемых assert-провала,3 проходящие проверки
сохранения поведения,6 проходящих старых регрессий**, ошибок/пропусков0.
Повторное продолжение с объединённой спецификацией получило тот же результат
и хеши четырёх файлов без обращения к модели.83 включённых исходника VR совпали
с исходным снимком. Programmer не запускался; `source_apply=false`,
`goal_complete=false`.

Спецификация готова для реализации этой ограниченной функциональности в копии.
Это ещё не полная приёмка задачи улучшения DWG: реальный файл, все варианты
стрелок/размеров, вложенные блоки и визуальное расположение не проверены.
Классы фикстур не доказывают соответствия всем данным реального DWG backend.

## Изменения COS

Общий `--extend-spec` сохраняет принятую приёмку и требует, чтобы дополнительные
тесты самостоятельно выявляли новый пробел и сохраняли работающее поведение.
Checkpoint связывает продолжение с исходной спецификацией, целью, проектом и
хешами. Прежние регрессии остаются обязательными; новый этап не вправе заменить
их или окружение. После квалификации объединённый checkpoint самодостаточен.

Контекст больше не повторяет автоматически исходники принятых регрессий.
Если модель запрашивает такой файл, он показывается на следующем вызове, затем
может быть убран из текста, оставаясь в источниках и исполнении. Повтор списка
уже показанных файлов и хеши исходников не включаются в текст SpecWriter;
проверки хешей внутри COS сохраняются. Готовые предметные случаи не переписываются.

Добавлен явный `--max-output-tokens`; default32768 сохранён. Для одного
дополнительного файла эксперимент использовал16384, затем8192. BudgetedChat
резервирует тот же лимит, который получает провайдер, с прежним запасом на
две upstream-попытки. Снижение лимита не обнуляет расход и не ослабляет предел1M.

и лимитом запроса, не выбора предметных примеров вместо модели. Данных о полноте
внешнего биллинга нет; usage — телеметрия провайдера/шлюза.
