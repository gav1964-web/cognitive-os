# Пакет из пяти шагов: доказательства и review, 17 сентября 2026

Продолжение [ограниченного повтора VR/5](description_repeat_20260917.md).
Пакет реализован и проверен без новых обращений к LLM. Предыдущий бюджет
из шести обращений остаётся закрытым. Исходные ответы COS не переписаны;
внешние проекты не запускались и не изменялись.

## Пять результатов

1. **Карточки утверждений.** Плагин project_description0.3.0 связывает утверждение
   черновика с его ссылками и точными вхождениями цитируемых значений в сохранённых
   выдержках. Вхождения содержат ID, путь, SHA256 и смещение. Совпадение не доказывает
   семантику, выполнение или доступность пользовательского сценария.
2. **Компактный контекст review.** Доказательства и карточки ограничены32тыс.
   символов сериализованного JSON. Полные receipts сохранены; модель получает
   сокращённые фрагменты и ограниченный каталог для единственного lookup.
   Все ID источников сохранены. Инструкция, черновик и история дают дополнительный
   объём запроса. Новая генерация на этом представлении ещё не измерена.
3. **Проверка обоснований.** Необязательные структурированные проверки
   `literal_absent` сверяются с теми выдержками, которые видел reviewer.
   Если значение присутствует, отрицание помечается противоречащим тексту.
   Старые свободные причины удаления проверяются только на пересечение
   цитируемых значений с кодом: это сигнал для review, а не разбор смысла причины.
4. **Незавершённая работа доходит до ролей.** `review_tasks` сохраняют стабильный ID,
   исходный текст, причину, источники и следующий шаг. Их пространство имён —
   черновик, поэтому переиндексация финальных сценариев не подменяет утверждение.
   Задачи передаются Analyzer → Architect → SpecWriter отдельно от принятых фактов.
   При timeout они сохраняются, а черновик не публикуется как готовое описание.
5. **Самостоятельный offline-аудит.** CLI `tools/audit_project_description.py`
   готовит карточки и задачи из сохранённого отчёта без модели и запуска
   исходников. Он проверяет актуальность хешей, не меняет оригинальный отчёт
   и не разрешает указать его же как output. Ассистент может продолжить по этим
   материалам без повторной передачи контекста владельцем.

Тесты и оформление доказательств выполнены для всего пакета; они не считаются
дополнительными шагами.
