два падения, 0 устранённых и 0 новых; исходный проект не изменён.

## Исправления COS, обусловленные измерением

1. `native_failure_acceptance.preflight_native_acceptance` повторяет baseline
   дважды тем же isolated runner до hypothesis/candidate запроса. Проверяются
   текущие hashes, повторяемость, recorded signature и неизменность копий.
   Несовместимые assertion mode, зависимости или изменившийся baseline дают
   локальный отказ с receipt. Paired acceptance и полная regression после патча
   остаются обязательными. Это preflight запросов ремонта; отдельный L3.5 caller
   анализа проекта пока находится раньше него и учитывается в transport budget.
2. Parser понимает квадратные subtest labels, включая пробелы и вложенные скобки,
   сохраняет и дедуплицирует родительские nodeid. Предел 8 разных родителей
   сохранён. Pathspec теперь даёт воспроизводимое падение с двумя parent nodeids,
   но остаётся unbound через helper/instance dispatch. Ремонт Pathspec не заявлен.
3. Analyzer разрешает прямой `Class(...).method()` только для собственного
   класса с обычным методом. Переиспользованы ограничения наследования, custom
   metaclass/dispatch, подмены имён и методов; непрозрачные observers не получают
   такую привязку. Это observed API, не автоматически доказанный root cause.
   Toml-sort теперь qualified с целью `toml_sort/tomlsort.py:TomlSort.sorted`.

Подтверждение preflight: исходные два теста падали, после изменения профильный
набор **33 passed**. Subtest parser: исходно 3 failed / 2 passed, после исправления
**8 passed** с соседними protocol tests. Constructor binding и subtests:
**14 passed**. Расширенная регрессия после изменений: **102 passed**.

Патч не доставлен в исходный проект. Успехов после вмешательства тоже 0.

Идентичности тестов обоих кандидатов сравнивались по полным JUnit. Удалён только
точный известный workspace-префикс соответствующей копии из classname; исходные
XML и первоначальный audit сохранены. Collection и прежние skips/xfails совпали.
Дальнейших model calls в этом этапе нет.

DeepSeek HTTP500, успешный ответ GigaChat-Pro, успешный ответ DeepSeek.
