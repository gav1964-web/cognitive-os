# Навигация и границы

Точка входа — [карта проекта](../../PROJECT_MAP.md). Единственный текущий индекс
статуса — [DEVELOPMENT_STATUS.md](../../DEVELOPMENT_STATUS.md). Подробные ролевые
таблицы и исторические прогоны остаются доказательствами с датой и областью действия.

Иерархия: исполняемый код/контракты/config определяют поведение; технический
baseline задаёт инженерные требования; текущий статус связывает утверждения с
измерениями; карта и briefs отвечают за навигацию. При расхождении зафиксировать
его и проверить соответствующий код/receipt, а не выбирать наиболее высокий балл.

Манифест `subsystems.json` содержит смысловое владение файлами, точки входа,
контракты, зависимости и команды тестов. Это курируемая карта ключевых файлов,
не исчерпывающая классификация каждого вспомогательного модуля. Неизвестный путь
в генераторе контекста требует уточнения карты; он не назначается области молча.

`project_context.py --check` проверяет существование ссылок и статические импорты
пакетов, включая строковые вызовы import_module. Неразрешимые динамические импорты
в пакетах требуют явного решения. Проверка не доказывает отсутствие всех
возможных динамических зависимостей или доступа к внешним данным.

Физическая структура: `packages/cognitive-inspect` и `packages/cognitive-replay`
имеют свои pyproject, API, тесты и установку. Остальной COS подключает их через
editable installs в development и обычные wheels при независимой проверке.
Старые пути — compatibility aliases для существующих plugin entrypoints и imports;
исправлять нужно canonical implementation в `src/`. Не копировать туда вторую
реализацию и не добавлять fallback в sys.path.

Подробное обоснование решения до извлечения:
[оценка компонентов](../../COMPONENT_MATURITY_ASSESSMENT.md). Следующее извлечение
допускается после независимых тестов и явных API; число файлов само по себе не повод.

Для следующих пяти обычных задач записывать: подсистему, время до нахождения
точки изменения, поздно обнаруженные зависимости, повторные правки после первого
решения и результат тестов. Сопоставлять задачи похожего типа. Сгенерированный
размер контекста — показатель навигации, не оценка интеллекта или качества решения.
Исходная оценка времени понимания не измерялась; обещанного прироста в процентах нет.
Для записи есть [шаблон наблюдения](TASK_REVIEW_TEMPLATE.md).

Инструкции AGENTS.md следуют механизму
[OpenAI Docs](https://developers.openai.com/codex/guides/agents-md).
Установка и проверка пакетов опираются на
[PyPA](https://packaging.python.org/en/latest/discussions/src-layout-vs-flat-layout/)
и [pytest](https://docs.pytest.org/en/stable/explanation/goodpractices.html).
